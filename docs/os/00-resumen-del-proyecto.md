# 00 - Resumen del proyecto

TaskFlowLab.Api es un laboratorio backend construido desde cero para practicar conceptos profesionales usando ASP.NET Core, C#, Clean Architecture moderada, Entity Framework Core, PostgreSQL, JWT, testing, Docker y CI/CD.

## Objetivo

Aprender construyendo una API real, tomando TaskFlow Pro API como repositorio de referencia, pero creando una version didactica paso a paso.

## Stack

- Lenguaje: C# (.NET 8)
- Framework: ASP.NET Core 8
- Persistencia: Entity Framework Core + PostgreSQL
- Autenticacion: JWT
- Testing: xUnit
- Contenedores: Docker
- CI/CD: GitHub Actions

## Reglas base

- Priorizar claridad sobre complejidad.
- No agregar tecnologias nuevas sin motivo.
- Escribir features pequeñas y testeables.
- Documentar decisiones importantes antes de implementarlas.
- Todo el codigo va en español: clases, metodos, propiedades, variables, interfaces, enums, commits y comentarios.
